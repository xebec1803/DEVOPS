WEEK 3 – NETWORKING MACHINE TEST

1. What is Networking?
Networking is the process of connecting two or more computers or devices so they can communicate and share information and resources.

2. Explain LAN, WAN, and Internet.
LAN (Local Area Network):

LAN connects computers and devices within a small geographical area, such as a home, office, or school.

WAN (Wide Area Network):

WAN connects networks over large geographical areas, such as different cities or countries.

Internet:

The Internet is a worldwide network of connected networks. It allows people and computers around the world to communicate and share information.

4. Explain the 7 layers of the OSI Model.

Layer 1 – Physical Layer:

This layer transfers raw bits through physical connections such as cables, switches, and signals.

Layer 2 – Data Link Layer:

This layer transfers data between devices on the same network using MAC addresses.

Layer 3 – Network Layer:

This layer handles IP addresses and helps find the path for data to reach another network.

Layer 4 – Transport Layer:

This layer manages communication between devices using protocols such as TCP and UDP.

Layer 5 – Session Layer:

This layer establishes, manages, and terminates communication sessions between applications.

Layer 6 – Presentation Layer:

This layer handles data formatting, encryption, and compression.

Layer 7 – Application Layer:

This layer provides network services to applications such as web browsers and email clients.

5. What is the TCP/IP Model?

TCP/IP stands for Transmission Control Protocol/Internet Protocol.

It is a networking model used for communication over the Internet and other networks. It explains how data is transferred between devices.

It has four layers:

Application Layer

Transport Layer

Internet Layer

Network Access Layer

7. What is an IP Address?

An IP Address stands for Internet Protocol Address.

It is a numerical address assigned to a device on an IP network. It helps identify devices and allows them to communicate with each other.

8. What is DNS?

DNS stands for Domain Name System.

It translates domain names into IP addresses so computers can find the correct servers.

9. What is ICMP?

ICMP stands for Internet Control Message Protocol.

It is used by network devices to send error messages and diagnostic information.

10. Why is Networking important in DevOps?

It helps DevOps engineers:

Connect applications with servers.

Troubleshoot network problems.

Manage communication between services.

Configure DNS, IP addresses, and ports.

Monitor network connectivity.

Deploy and manage applications in cloud environments.

Part 3: Explain the Following Commands

1. What does ping do?

The ping command checks network connectivity between two devices by sending ICMP echo requests and waiting for replies.

2. What does curl do?

The curl command transfers data to or from a server using URLs. It can be used to test HTTP and HTTPS connections and retrieve website content.

3. What does ip a do?

The ip a command displays network interfaces and their IP address information in Linux.

4. What does hostname -I do?

The hostname -I command displays the IP addresses assigned to the system.

5. What does nslookup do?

The nslookup command is used to query DNS servers and find information about domain names and their IP addresses.

6. What does traceroute do?

The traceroute command displays the network path taken by packets to reach a destination. It helps identify network routing problems.
